#Portfolio de proyectos

Repositorio que reúne diferentes proyectos desarrollados durante mi formación y aprendizaje en programación y desarrollo de software.

Actualmente estoy cursando **Desarrollo de Aplicaciones Web (DAW)**, después de haber completado **Desarrollo de Aplicaciones Multiplataforma (DAM)**, y con la intención de continuar mi formación en **Ciberseguridad**.

Los proyectos de este repositorio tienen como objetivo aplicar de forma práctica los conocimientos adquiridos en diferentes áreas del desarrollo de software.

##Proyectos

---ShopFlow — Plataforma de comercio electrónico
Aplicación web de comercio electrónico desarrollada para poner en práctica
conocimientos de desarrollo frontend y backend.

**Características:**
- Registro e inicio de sesión de usuarios.
- Gestión de productos y categorías.
- Carrito de compra.
- Gestión de pedidos.
- Panel de administración.
- Validación de formularios.
- Gestión de sesiones y permisos.

**Tecnologías:** PHP · MySQL · JavaScript · HTML5 · CSS3

---TaskFlow — Gestión de proyectos y tareas
Aplicación web para la gestión de proyectos y tareas, desarrollada mediante
una arquitectura basada en API REST y frontend independiente.

**Características:**
- Gestión de usuarios.
- Creación y administración de proyectos.
- Gestión y asignación de tareas.
- Estados y prioridades.
- Autenticación.
- Comunicación mediante API REST.
- Interfaz web dinámica.

**Tecnologías:** Angular · TypeScript · PHP · MySQL · REST API

[🔗 Ver proyecto](./taskflow)

---

---ChatBox — Aplicación de comunicación cliente-servidor
Aplicación de comunicación desarrollada en Java utilizando una arquitectura
cliente-servidor para trabajar con conexiones de red y comunicación
concurrente.

**Características:**
- Registro e inicio de sesión.
- Comunicación entre usuarios.
- Salas de conversación.
- Usuarios conectados.
- Gestión de múltiples conexiones simultáneas.
- Persistencia de información.

**Tecnologías:** Java · JavaFX · Sockets · Multithreading · MySQL

[🔗 Ver proyecto](./chatbox)

---

---FitTrack — Aplicación Android
Aplicación móvil orientada al registro y seguimiento de entrenamientos,
desarrollada como proyecto para aplicar conocimientos de desarrollo Android.

**Características:**
- Gestión de usuarios.
- Registro de entrenamientos.
- Gestión de ejercicios.
- Registro de series, repeticiones y peso.
- Historial de entrenamientos.
- Estadísticas de progreso.
- Persistencia de datos.

**Tecnologías:** Kotlin · Android Studio · SQLite · REST API
